# KL-to-teacher anchoring for the vendored PPO learner.

Blue role, 2026-10-02. `third_party/` is gitignored, so this diff is recorded
here instead of the vendor tree. Follows the same convention as
ppo-warmup.README.md.

Why it exists: MAPPO fine-tuning from the BC-distilled factorized actor
collapses monotonically (-205 init -> -512 -> -1072 -> -1461 -> -1770 over
8 seeds; proposal 02), while the distilled init itself is decent. Sparse
noisy rewards unlearn the distilled ordering within ~3000 env steps. The
anchor is a frozen copy of the demonstrator actor: PPO minimises
KL(teacher || current) on the masked action distributions alongside the
clipped surrogate loss, so the policy can only drift where the advantage
signal pays for it.

What it does (all additive, all default-off):

1. Module-level `teacher_kl(pi, teacher_pi, mask)`: mean KL over valid
   (batch, time, agent) triples. Unit-tested in
   tests_blue/test_kl_teacher.py.
2. `__init__`: reads `kl_teacher_ckpt` (dir with agent.th) and
   `kl_teacher_coef` via getattr (upstream configs unaffected). Builds a
   frozen deepcopy of the MAC and loads the teacher actor weights, strict.
3. `train()`: one frozen teacher forward sweep per batch (not per epoch),
   `pg_loss += coef * KL`. Logged as `kl_teacher`.
4. `cuda()`: moves the teacher alongside everything else (CPU-only here,
   hygiene for later).

Inactive unless a ckpt dir AND a positive coefficient are both configured.
Driver flags: `--kl-teacher-ckpt DIR --kl-teacher-coef 0.1`
(blue_train_mappo.py build_config/CLI).

Apply AFTER ppo-warmup.patch (one hunk sits adjacent to the warmup block;
applying in the wrong order fails loudly at that hunk):

    git apply environment/patches/ppo-warmup.patch
    git apply environment/patches/ppo-kl-teacher.patch

Generation/verification: the patch was generated by `diff -u` between the
working file and a reconstruction with the KL hunks stripped, then applied
to a copy of the reconstruction and byte-compared against the working file
(verifier: /tmp/opencode/verify_kl_patch.py, scratch, not committed).
Do NOT hand-edit hunk headers; regenerate with diff if the learner changes.

Measured effect: pending (first KL run below). Run command for the record:

    ../.venv-train/bin/python blue_train_mappo.py --agent rnn_factorized \
      --steps 400 --t-max 12000 --seed 7 --train-seeds 7629 7630 7640 \
      --save-interval 2000 --lr 1e-5 --temporal-groups ages belief \

      --kl-teacher-ckpt results/models/bc_rr_20261002T082810Z/0 \
