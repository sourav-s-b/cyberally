Key Findings

  • JuiceShop remained the primary attack surface — 62% of all attack vectors targeted its checkout and authentication endpoints.
  • BlueAgent-2 demonstrated the highest containment rate (94%) among all defense agents during this run.
  • Critical host compromise events were reduced by 18% compared to Simulation Run 4, indicating improving MARL policy convergence.
  • Data exfiltration occurred in 3 of 48 attack chains, all originating from the DVWA subnet before Blue agents applied egress filtering.

Recommendations

  • Increase observation window for BlueAgent-1 to reduce response latency on brute-force login detection from 2.1s to under 1.5s.
  • Introduce micro-segmentation policies for the DVWA subnet to prevent lateral movement to the Web Server zone.
  • Retrain Blue Team policies with higher penalty weighting on data exfiltration events (-35 vs current -25) to prioritize egress filtering.
  • Consider expanding the Red Team repertoire with RCE chains targeting CVEs in the internal RPC microservices layer.

CyberAlly Architecture Documentation

CAGE-4 Simulation, Autonomous LLM Red Team & MARL Blue Agents

1. System Overview

CyberAlly provides a closed-loop autonomous cyber warfare simulator combining large language model (LLM) agents for offensive threat generation and multi-agent reinforcement learning (MARL) for defense orchestration.

2. Red Team Engine

Uses iterative prompting and threat graph decomposition to synthesize realistic attack vectors against containerized subnets, executing SQLi, RCE, and lateral movement.

3. Decentralized MARL Defense

Zone-specific Blue agents operate with partial observability, coordinating through decentralized policies to isolate compromised nodes, enforce microsegmentation, and patch zero-day vulnerabilities.

4. Negative Penalty Scoring

CyberAlly tracks a cumulative negative penalty score across each simulation run. Critical host compromises, data exfiltration events, policy violations, lateral movement, and repeated failed attempts each contribute negative scores to drive Blue Team policy improvement.
