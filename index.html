CyberRangeAI Architecture Documentation

CAGE-4 Simulation, Autonomous LLM Red Team & MARL Blue Agents

1. System Overview

CyberRangeAI provides a closed-loop autonomous cyber warfare simulator combining large language model (LLM) agents for offensive threat generation and multi-agent reinforcement learning (MARL) for defense orchestration.

2. Red Team Engine

Uses iterative prompting and threat graph decomposition to synthesize realistic attack vectors against containerized subnets, executing SQLi, RCE, and lateral movement.

3. Decentralized MARL Defense

Zone-specific Blue agents operate with partial observability, coordinating through decentralized policies to isolate compromised nodes, enforce microsegmentation, and patch zero-day vulnerabilities.
